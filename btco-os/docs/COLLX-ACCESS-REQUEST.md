# CollX integration access request

Prepared for Tim Ballard’s review. Not sent.

To: support@collx.app
Subject: Supported CollX integration access for Ballard Trading Co.'s own inventory app

Ballard Trading Co. is building BTCore, our private inventory application, and needs to manage our own CollX listings directly without routing through Card Dealer Pro. Could you confirm whether supported seller or partner API access is available and share the application process and documentation?

We need seller authentication and account identification; listing/catalog reads; original photo upload; create, revise price/details and end listing; orders, reservations, cancellations and refunds; and webhooks or bounded polling. Please include rate limits, idempotency/readback behavior, required seller plan, sandbox or read-only testing options, and rules for integration-managed listings. If there is a supported bulk import route, please share its exact schema, image requirements, duplicate detection and result reports.

We will preserve exact SKU and storage mappings, use independent CollX prices, require complete owner review before publication, and begin with a small explicitly approved live pilot. We will not treat an unconfirmed write or missing listing as proof of a sale.
