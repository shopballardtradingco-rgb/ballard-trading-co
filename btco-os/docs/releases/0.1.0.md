# Vault foundation 0.1.0

## Scope
Complete the partially committed Python foundation and its operator CLI. Preserve the original public connect/import/overview functions and original tables.

## Data
Additive review_flags table. Exact CDP identity is explicit and never inferred from an unknown eBay alias. Missing feed entries retain identity and last quantity. No private datasets included.

## Verification
10 unittest cases passed. The Python 3.12 wheel built, installed in an isolated virtual environment, and its CLI ran successfully outside the source directory. The recovered browser baseline passed 126 tests; the independent connector passed 48. A code commit is not a deployment.

## Limitations
No live API transport or schedule in this milestone. This SQLite database is separate from the existing browser app's D1 store. No physical stock, sales ledger or multi-tenant service is introduced.

## Rollback
Restore prior GitHub source for inspection only: its CLI/tests were empty. Back up the SQLite file before any downgrade. The added table can remain; do not delete records to roll back code.
