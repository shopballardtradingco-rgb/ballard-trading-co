# BTCore 0.4.0 — direct card publication through BTConnect

Core can connect the owner's eBay account, transfer original JPEG/PNG card photos, select existing seller policies and 5% promotion, review all listing text/photos/condition descriptors, and approve/publish a batch without CDP. Graded and ungraded card descriptors come from current eBay metadata. One front photo is sufficient; prices remain whole dollars and master SKUs remain exact.

Preparation is saved per photo/card. Invalid cards remain exceptions; groups of at most ten cards keep connector requests bounded. Each group preserves its storage location. Reloading resumes the same remote batch/draft IDs. The final explicit owner action approves exact remote revisions; development permission never publishes inventory. The existing Connect publication journal handles duplicate checks and uncertain write read-back. Verified item links are retained in Core.

The open workspace still does not require a password. Publishing requires a separate eBay OAuth connection on that device, with PKCE, browser-bound one-use state and an encrypted HttpOnly token cookie. Tokens never enter workspace exports or browser JavaScript. Logout of that connection clears the device cookie; account revocation is available through eBay/BTConnect.

Configure BTCONNECT_ORIGIN and a random BTCORE_CONNECTOR_KEY in Core, and the exact BTCORE_CALLBACK_URL in Connect. Existing databases and original photo storage are unchanged. No database migration is required.

Validation: Core unit/API tests, simulated mobile browser publication, existing preparation browser acceptance; Connect card tests and full regression suite. No real inventory publication is part of development validation. Owner eBay authorization and an explicitly approved live pilot remain necessary to verify real marketplace acceptance.

Current limits: flat-rate card shipping only; JPEG/PNG originals; existing Connect 300 MB photo quota remains. eBay inventory/sales import and automatic stock reconciliation are separate work. Live listing publication is not a sale and does not decrement physical inventory. This release does not yet replace every CDP function.
