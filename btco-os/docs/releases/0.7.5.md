# BTCore 0.7.5

A completed preparation containing photo failures previously made Get ready to publish a no-op. The button now requests one explicit retry of ungrouped exceptions. Saved shipping settings and photo references survive, submitted connector batches keep their identities, and additional prepared cards receive new group identities. Ordinary continuation never automatically retries exceptions. Approved publication batches cannot enter this retry path.

Validation: service regression covers partial success, retained groups, bounded retries and no publication; browser regression covers complete upload failure, reload and the same visible retry button. Existing release CI supplies broader browser and storage checks. Live publication still requires owner review and approval.
