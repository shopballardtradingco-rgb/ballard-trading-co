# BTCore 0.6.1 — Received-card price confirmation

A received card could require price confirmation while every price control rejected it, preventing listing approval. Review cards now exposes Check price and Edit price for received cards. The narrowly scoped server operation updates the linked Vault asking price and intake price together, confirms the owner price, and requires fresh listing approval. It preserves the received status, item ID, SKU, quantity, original photos and condition details. Saved eBay batches and listed inventory block this edit. Other received-intake editing remains locked.

The Finish remaining button counts only editable unfinished cards. Instructions point to Check price for price confirmation.

Validation: 64 local tests pass (PostgreSQL runs in exact-head CI); mobile pricing regression covers receiving a legacy-price card, confirming $7, retaining one stock record and approving listing details without creating a publishing batch. Exact-head independent-runtime, browser and vault CI must pass before promotion. No database migration or marketplace publication is included.

Core still requires final eBay batch review and explicit publication approval. CollX direct posting and automatic delisting remain disconnected. See docs/CDP-REPLACEMENT.md for the parity ledger.
