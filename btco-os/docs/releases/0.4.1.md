# BTCore 0.4.1

Mobile card review and intake details now expose Edit price directly, with a focused decimal input and Save price button. Previously approved drafts can be edited; content-bound approval becomes stale after a price change. Original photos and all other fields remain intact. Saved eBay batches require removal/rebuild before quick editing; already approved publication is not modified. This release changes price editing, not price research or valuation.

Validation: mobile browser edits an approved card, checks rounding, approval invalidation, persistence after reload and unchanged photos; existing preparation browser flow and Core unit tests.
