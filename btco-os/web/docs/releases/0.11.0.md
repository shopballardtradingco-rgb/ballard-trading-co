# Browser 0.11.0 — canonical GitHub consolidation

## Scope
Maintain the existing browser application inside canonical GitHub web/. Add searchable Market channel observations and duplicate identities, Flow reconciliation queues/history, and Scout's fee-aware purchase worksheet. Retain Vault, Vision and Pulse. Add reusable sequential listing collection with full-batch validation.

## Data
No schema migration or runtime re-import. Remove bundled historical inventory/channel JSON and the automatic source seeding step. Existing authenticated D1 inventory and device recovery copies remain intact. New accounts start empty. Test the same 3,817-record scale with synthetic records. Keep recovered SwiftUI archives unchanged with fingerprints.

## Verification
126 baseline browser tests passed after replacing private datasets with synthetic fixtures. Additional module and multipage collector tests, release metadata, typecheck and production build are release gates. Live read-only eBay collection and persisted readback verified separately on October 11 Pacific: 3,573 listings across 18 pages, workspace revision 3; no CDP SKU conflicts, 69 quantity review differences and 32 missing observations. The existing 7 AM Pacific daily schedule was observed enabled; future executions are not yet evidence of success.

## Limitations
Browser/Safari visual acceptance and native iPhone compilation/camera checks remain unverified. Scout is a worksheet, not automated sourcing. CollX prices can be recorded but live retrieval is not connected. Flow does not infer sales or alter physical stock. Shared-account isolation is not a commercial tenant membership system. Provider configuration remains independent of this release.
