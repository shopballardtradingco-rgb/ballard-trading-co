# BTCo OS 0.10.0 — Daily eBay inventory refresh

## Scope

Connect the working active-listings reader to a narrow unattended inventory writer. Validate all pages, seller identity, duplicate IDs, totals and timestamps. Preview/apply/readback uses the current shared workspace revision. Display API source time, active-listing counts, conflicts and overdue observations. Add a committed daily runbook and hidden-stdin client; schedule only after live verification.

## Data

No schema migration or seed replacement. Preserve all CDP master SKUs, existing inventory aliases and source evidence, identity, quantities, costs, sales, CollX prices and review exclusions. Update eBay observations and non-manual eBay prices. New listings become review records with zero physical units. Missing listings are observations, not inferred sales. Block relisting alias collisions and variations. Retain existing atomic commits and recovery snapshots; identical payloads replay safely. Runtime configuration binds only the existing owner workspace and verified seller. Original visitor authorization remains unchanged.

## Verification

Live connector collection returned 3,573 unique listings across 18 pages with unchanged totals, 123 blank listing SKUs and no variations. A dry run against original seed matched 3,504 records and proposed 69 review records; the actual live workspace must be previewed independently. Added regression coverage for incomplete/stale/foreign/duplicate collections, CDP and physical inventory preservation across the complete baseline, manual prices, aliases, variations, missing listings, replay, SQLite persistence, owner isolation and stale device edits. All 125 tests in the existing and expanded suite passed, followed by one full-inventory workerd/D1 persistence test (126 total). TypeScript, release/provenance checks and whitespace checks passed. The production build remains a required Sites packaging gate. Publication mapping and the live writer result are reported at handoff.

## Limitations

Paginated active listings are not an atomic snapshot. CDP export is not connected; historical CDP/CollX enrichment is not refreshed by eBay. No automatic sold-order reconciliation, physical stock sync or marketplace writes. New records need identity/stock review. The unattended writer relies on confirmed owner-private Sites access plus explicit server-side workspace/seller scope; disable it before sharing publicly. Browser-control QA and physical iPhone testing are unavailable. The October 11 browser CSV upload restriction is unchanged; fresh API data uses a separately authorized integration.
