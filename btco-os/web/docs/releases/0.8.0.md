# BTCo OS 0.8.0 — Public PSA certificate lookup

## Scope

Keep the working scan/review/receive flow moving while PSA API access is restricted. Add an editable public certificate lookup in Vision with Google search and official PSA record links. Default the separate research input to `24311536`; actual PSA scans, restored results and grader/certificate edits synchronize it to the card. New/non-PSA cards clear it. Add both links to saved PSA Vault records. Move optional API setup below the main flow, leave it collapsed and hide the automated check button until a connection exists.

## Data

No schema migration, inventory import, secret change, access-policy change or new paid provider. Research links send only the numeric certificate and open in a new tab with no opener/referrer. An exact numeric validator retains leading zeroes and rejects arbitrary URLs or search operators. Opening/editing research links never updates inventory or sets a verification flag. Public results are not scraped, cached or imported as API evidence. Existing reviewed receipt and credential verification rules remain in force.

## Limitations

Public results open outside BTCo OS for manual review; they are not automatically imported. External search indexing and PSA page availability can change. Browser automation is unavailable in this environment, so no physical-iPhone or browser acceptance test is claimed. API approval remains a separate external issue and no longer blocks the public lookup workflow.
