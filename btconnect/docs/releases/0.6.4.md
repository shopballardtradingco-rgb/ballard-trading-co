# 0.6.4 — Visible eBay sign-in continuation

The browser could remain on the consent form after an external redirect, even
though consent had been consumed. A repeated click then returned an invalid
request. Browser HTML requests now receive a visible eBay sign-in link after
the same CSRF and browser-bound consent validation. A link starts a fresh
navigation outside the form redirect chain. Non-HTML clients retain the 303
response. Core's consent page now identifies BTCore correctly.

Regression coverage checks both negotiated responses, exact eBay destination
and original state, Core page identity, unchanged callback rejection and
authorization policies. No seller grant or listing approval is fabricated;
sign-in and exact reviewed publication remain distinct acceptance steps.
