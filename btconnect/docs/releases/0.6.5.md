# 0.6.5 — Preserve phone JPEG/MPF originals

A live Core original had a JPEG signature and two embedded MPF pictures.
Pillow identified it as MPO; the connector rejected it with "Use an original
JPEG or single-frame PNG" before any listing draft could be prepared.

PhotoStore now accepts JPEG/MPF originals with at most two pictures, decodes
both, and applies the existing dimension and aggregate 40-million-pixel bound.
PNG remains single-frame. Original bytes, SHA-256, encryption, duplicate lookup
and the JPEG object extension are preserved. No conversion, stripping or
replacement photograph is performed.

Synthetic tests cover the real ticket/upload route, exact stored-byte readback,
duplicate reuse, rejected extra frames, animated PNG and corrupt auxiliary
JPEG data. Live re-preparation and exact owner approval remain separate gates;
accepting an original into private storage does not publish it to eBay.
