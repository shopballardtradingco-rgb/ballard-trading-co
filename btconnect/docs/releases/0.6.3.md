# 0.6.3 — Core OAuth return-path repair

The consent form's browser redirect policy allowed ChatGPT and eBay but omitted
the explicitly configured Core callback origin. The consent POST also reverted
to a self-only policy while returning an external redirect. Both consent
responses now allow the configured Core origin, preserving the exact callback
registration checks, CSRF validation, PKCE and existing seller authorization.
Unconfigured origins remain rejected. No marketplace scope, listing approval,
inventory, credential or photo storage changes are made.

Regression tests exercise a real HTTP registration/authorization/consent flow
with a configured Core host and non-default HTTPS port, both response policies,
the strict policy on unrelated pages, and rejection of unconfigured callbacks.
The ChatGPT-only policy remains bounded. Live browser sign-in and an exactly
reviewed listing are separate acceptance steps; tests do not claim publication.
