# Connector 0.3.4 — owner-authorized shipping estimates

Actual measurements are not a prerequisite for preparing calculated shipping when the owner has explicitly authorized a reasonable estimate. This release adds a truthful estimate path rather than marking estimated data as measured. It does not authorize assumptions about a comic's printing, variant, interior completeness or condition.

## Gemini single-comic profile

Assumption: the standard Gemini Comic Flash Mailer, one ordinary raw single issue, one bag and board, tape and shipping label. This profile is not for slabs, trade paperbacks, larger mailer models or combined orders.

| Component | Weight | Basis |
| --- | ---: | --- |
| Standard Gemini Flash Mailer | 4.8 oz | Manufacturer specification |
| One comic | 3 oz | Allowance; publisher/distributor examples of 32-page singles list 2–4 oz |
| One board | About 0.69 oz | BCW's 4.30 lb / 100-board pack |
| One bag | About 0.18 oz | BCW's 1.13 lb / 100-bag pack |
| Tape and label | 0.5 oz | Allowance |
| Estimated total | About 9.2 oz | Component sum 9.1688 oz; inputs are approximate |
| Listing estimate | **12 oz** | Approximately 2.8 oz buffer |

Bag/board pack weights may include outer packaging; their per-piece weights are estimates. The manufacturer publishes outer dimensions of 12.75 x 7.75 x up to 1.25 inches. The listing profile rounds these up to **13 x 8 x 2 inches**. Final postage uses the actual fully packed weight; added packaging can change it. The profile never supplies an invented measured weight for any physical copy.

## Contract and approval behavior

`packed_parcel` supports two distinct paths:

- `basis: "measured"`, `verified: true`, `estimate: null`, and measurement evidence.
- `basis: "owner_authorized_estimate"`, `verified: false`, with calculation evidence and an `estimate` object containing the owner's actual authorization text plus public HTTPS `source_urls`.

The default remains measured. A missing authorization, missing sources, a false measured flag, or an estimate labeled verified is rejected. No draft silently acquires an estimate. Source references are evidence, not URLs that the server fetches.

`get_listing_readiness` exposes the public profile and identifies the authorization requirement. The Python `authorized_gemini_parcel` helper produces parcel data from actual supplied permission; it never approves a listing. All package data, provenance, sources and authorization participate in the exact revision hash. A changed revision clears listing approval. Publication still requires a separate owner-approved complete draft, original-photo integrity, identity evidence, business policies, duplicate checks and post-publication read-back.

Older serialized approvals cannot silently adopt the added provenance fields. Re-save and review under the current contract where needed. Pilot drafts have not been saved as complete or published, so no pilot approval record is migrated by this release.

## Verification

191 tests pass with simulated eBay calls and synthetic listing fixtures. The suite verifies rejection of false measurement claims, missing estimate authorization/sources, approval invalidation, calculated-shipping transport, stable publication retries, and the continued requirement for verified comic identity. Existing credentials, scopes, shipping policies, campaigns and live inventory are not changed. Publication remains disabled pending the remaining comic-specific evidence and complete approved drafts.
