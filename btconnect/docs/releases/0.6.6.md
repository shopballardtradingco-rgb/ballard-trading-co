# BTConnect 0.6.6

Live inventory read-back returned a #10 envelope width of 4.13 inches for the approved 4.125-inch input. All other approved content matched. The strict comparison incorrectly stopped publication before offer creation.

The comparison now accepts exact two-decimal ROUND_HALF_UP representation for INCH length and width only. It does not change saved drafts, approval revisions, requested shipping payloads or originals. Weight, thickness and converted units remain exact, and adjacent hundredths and added precision are rejected. This is based on observed eBay responses; it is not a general claim that eBay documents uniform rounding for all parcel fields.

Regression tests reproduce a persisted inventory-only failure, resume that same job after the comparison repair and verify one inventory write, one offer and one publish. Batch exceptions remain paused; explicitly resumed approved drafts still undergo all normal content, policy and duplicate checks. No uncertain publish is retried or rearmed.
