# BTConnect 0.6.2 existing photo capacity

The preparation pass measured enough unused space on the existing volume to
raise its photo ceiling from 300,000,000 to 400,000,000 encrypted bytes. The
independent 50,000,000-byte free-disk reserve remains enforced for every new
original. Actual disk headroom can be lower than the quota headroom and is
reported by readiness. Existing records and originals are unchanged.

This uses the existing service and volume under the owner's established cloud
budget. It does not resize the volume, subscribe to a service or migrate data.
The next batch still needs sizing from its actual photo bytes. A capacity
estimate based on previous averages is not a guarantee that all incoming files
fit; retain successful uploads and resume only outstanding ones.

Validation includes the complete connector regression suite and explicit
boundary tests showing the higher ceiling accepts eligible originals while a
low free-disk reading still blocks writes. Deploy with the same keys and volume;
verify version, headroom and unchanged catalogs. No new comic is a release test.
