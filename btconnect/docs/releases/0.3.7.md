The owner explicitly directed: use Good, or Acceptable for rough copies, and never a higher label. The comic draft contract now permits only `USED_GOOD`, `USED_ACCEPTABLE` or an unspecified legacy value. No numerical grade or interior inspection is inferred. Exterior-only drafts still require the uninspected-interior sentence in their complete approved main and condition descriptions; unknown printing and variant remain unspecified.

## Safe condition changes before offer creation

One pilot inventory item existed when the owner changed the condition instruction, but no offer had been attempted. The connector can now stage a **condition-only** change to that same inventory item through `save_listing_draft`:

1. Acquire the seller lock and compare the supplied prior revision with the saved approved revision.
2. Require the same physical item, master SKU/marketplace alias, original photographs and every other draft field. Refuse any offer/publish attempt, saved offer/listing ID, completed receipt, incomplete media or already pending revision.
3. Verify through eBay GETs that no offer exists and the inventory item exactly matches the prior approved content.
4. Preserve the prior draft, approval and publication journal in revision history. Clear approval of the new revision. No eBay write occurs at this stage.
5. Require explicit approval of the changed revision. Before writing, recheck policy, duplicates, originals, absence of offers and unchanged remote inventory.
6. Journal the update intent, write the new condition to the **same SKU** with the same photographs, and verify read-back. If the write response is lost, recover only through read-back; never overwrite a different item or create duplicate offers.

Any wider started-job revision remains blocked. This does not enable repricing or modifying existing marketplace listings, changing CDP identifiers, or resetting an uncertain offer/publication attempt.
