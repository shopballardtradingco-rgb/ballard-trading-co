# 0.3.10 — Five-dollar comic offer rule

Owner instruction, October 13, 2026: comic listings priced at $5 have offers OFF.

- New or revised $5 review drafts must disable Best Offer and omit the offer floor.
- Other asking prices retain Best Offer and an explicit reviewed minimum.
- The outgoing $5 offer contains only `bestOfferEnabled: false`; no auto-decline or auto-accept amount is sent.
- Existing live listings are not edited. Changing a saved draft creates a new exact revision and clears approval as before.
- No listing publication is authorized by this software release.
