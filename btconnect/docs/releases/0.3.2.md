# Connector 0.3.2 — approved Best Offer minimums

The owner requested Best Offer on each pilot listing, with a minimum two dollars below its asking price. These are preparation instructions; final approval of the complete listing and original photos is still required before publication.

| Pilot | Asking price | Minimum offer |
| --- | ---: | ---: |
| Elementals #6 | $8 | $6 |
| SuperPatriot #1 | $7 | $5 |
| StormWatch #1 | $8 | $6 |
| Journey #2 | $10 | $8 |
| Elfquest: Siege at Blue Mountain #4 | $7 | $5 |

Drafts accept `best_offer: {"enabled": true, "minimum_offer_usd": "6"}`. Both the asking price and minimum must be positive whole dollars, and the minimum must be below the asking price. The two-dollar difference is this batch's instruction, not a silently imposed global discount. Offers default to disabled for other drafts.

The Sell API payload sets `listingPolicies.bestOfferTerms.bestOfferEnabled` and `autoDeclinePrice`. It never sends `autoAcceptPrice`; offers at or above the minimum remain for the seller to decide. Unsupported categories or changed terms stop the workflow rather than silently dropping the requested minimum.

All offer settings are included in the revision fingerprint. Enabling offers, changing the minimum, or disabling offers clears approval. Drafts approved under an older contract need to be saved and approved again; no approval is migrated or inferred. Exact CDP identifiers, original photos and duplicate-publication protections remain in place.

Offer read-back compares the minimum numerically in USD, accommodating eBay's equivalent decimal formatting. Unexpected automatic acceptance, missing or changed floors, and changed enabled state block verification. The check runs before publication and on the published offer; an unexpected post-publication change leaves the existing job for reconciliation and does not trigger another publication.

Validation: 129 automated tests pass using synthetic images and simulated eBay responses, including approval invalidation, invalid minimums, read-back drift, and a lost publish response. No live listings or eBay offers are created by this release. Publication remains disabled while measured calculated-shipping support, identity/interior checks, final drafts, and reviewed campaign settings are completed. Account scopes already consented in production remain unchanged.

Reference: [eBay Best Offer API guidance](https://developer.ebay.com/develop/guides/sell/other-apis-guide) and [minimum offer / auto-decline behavior](https://www.developer.ebay.com/api-docs/user-guides/static/trading-user-guide/best-offers-auto.html).
